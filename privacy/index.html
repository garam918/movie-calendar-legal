앱에서 사용하는 정보

영화달력은 한국 극장 개봉 일정을 탐색하고 알림을 예약하는 앱입니다. 현재 버전은 게스트 모드를 제공하며 Google 로그인과 기기 간 동기화는 준비 중입니다.

관심목록과 알림
관심 영화와 팔로우한 인물의 식별자, 알림 설정·예약 기록을 앱 내부 저장소에 보관합니다. 저장한 항목을 다시 보여주고 기기에서 개봉 알림을 예약하는 데 사용합니다.
홈 화면 위젯
위젯을 추가하면 관심 영화의 제목과 가장 가까운 확정 개봉일을 사용해 D-Day를 표시합니다.
캘린더 추가
캘린더 추가를 선택하면 영화 제목과 개봉일을 기기의 캘린더 편집기에 전달합니다. 편집기에서 일정 저장을 선택한 경우에는 해당 캘린더의 보관·동기화 설정이 적용됩니다.

웹 방문과 문의

이 문서 사이트는 GitHub Pages에서 제공됩니다. GitHub는 사이트 보안을 위해 방문자의 IP 주소를 기록하고 보관합니다. GitHub의 처리 방법은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

문의 메일을 보내면 발신 이메일 주소와 본문에 적은 정보를 접수합니다. 가람랩은 내용을 확인하고 처리 결과에 회신하는 데 사용합니다. 문의 메일의 수신과 회신에는 Google Gmail을 사용합니다. Google 개인정보처리방침에서 메일 서비스의 정보 처리 방식을 확인할 수 있습니다.

보관과 삭제

  • 기기 정보는 앱에서 항목을 해제하거나 앱을 삭제할 때까지 보관합니다. Android에서는 기기 설정에서 앱 데이터를 지울 수 있습니다. 기기의 백업에는 운영체제 설정이 적용됩니다.
  • 캘린더에 저장한 일정은 해당 캘린더에서 삭제할 수 있습니다.
  • 문의에 필요한 정보는 요청 처리가 끝날 때까지 보관한 뒤 메일함에서 삭제합니다. 관계 법령에 따라 보관 의무가 생기는 경우 규정된 기간 동안 보관합니다.

권리 행사와 연락처

이용자와 법정대리인은 개인정보의 열람, 정정, 삭제 또는 처리 정지를 요청할 수 있습니다. 삭제 요청을 포함한 개인정보 문의는 가람랩 개인정보 문의 담당(dev.garam918@gmail.com)으로 보내 주세요. 요청 내용과 회신 가능한 주소를 알려주시면 필요한 범위에서 본인 또는 대리인 여부를 확인하고 처리 결과를 안내합니다.

방침 변경

개인정보 처리 방식이 달라지면 이 페이지에 변경 내용과 적용일을 게시합니다. 계정·동기화 기능을 활성화하기 전에 인증 및 서버 보관 정보, 처리 위치와 삭제 방법을 이 방침에 반영합니다.
