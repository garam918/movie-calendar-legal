앱에서 사용하는 정보

가람랩은 영화달력의 한국 극장 개봉 일정과 관심목록, 알림 기능을 제공하기 위해 아래 정보를 처리합니다. 로그인 없이 개봉 일정을 보고 관심목록을 사용할 수 있습니다.

기기에 저장하는 정보
관심 영화와 팔로우한 인물의 식별자, 알림 설정과 예약 기록을 기기에 보관합니다. 저장한 항목을 표시하고 기기에서 개봉 알림을 예약하는 데 사용합니다. 검색어는 기기에서 내려받은 영화 목록을 검색하는 데 사용합니다.
로그인 정보
계정 기능이 활성화된 앱에서 Google 또는 Apple 로그인을 선택하면 Firebase Authentication이 로그인 제공자, 계정 식별자, 제공자가 전달한 이메일 등 계정 정보와 인증 토큰을 처리합니다. 로그인, 계정 식별과 재인증에 사용하며, IP 주소와 브라우저·앱 접속 정보는 인증 보안에도 사용됩니다. Apple 로그인은 해당 기능이 활성화된 iOS 앱에서 제공됩니다.
기기 간 동기화
로그인 계정의 Firebase 사용자 식별자에 연결해 관심 영화와 팔로우 인물의 식별자 및 저장·해제 상태, 알림 사용 여부와 시각, 변경 순서와 중복 처리를 확인하는 기록을 Cloud Firestore에 저장합니다. 같은 계정의 다른 기기에서 이 정보를 불러올 수 있습니다. 게스트 목록과 설정은 이용자가 계정에 복사하기로 선택하면 동기화됩니다.
개봉일 변경 푸시 알림
개봉일 확정·변경 알림이 켜져 있고 기기 알림이 허용된 경우, 앱은 Firebase Cloud Messaging(FCM)에 기기 등록 토큰을 만들고 관심 영화별 알림 주제를 구독합니다. FCM과 Apple 푸시 알림 서비스는 토큰과 구독 주제로 메시지를 기기에 전달합니다. 가람랩 서버는 등록 토큰이나 관심목록을 받거나 저장하지 않고, 영화별 주제로 영화 제목과 개봉일 변경 내용만 보냅니다. 알림에는 관심 영화의 제목이 표시되며, 잠금 화면 노출 여부는 기기 알림 설정을 따릅니다. 영화를 관심목록에서 빼거나 변경 알림을 끄면 해당 주제 구독을 해제합니다.
홈 화면 위젯
위젯을 추가하면 관심 영화의 제목과 가장 가까운 확정 개봉일을 사용해 D-Day를 표시합니다.
캘린더 추가
캘린더 추가를 선택하면 영화 제목과 개봉일을 기기의 캘린더 편집기에 전달합니다. 편집기에서 일정 저장을 선택한 경우에는 해당 캘린더의 보관·동기화 설정이 적용됩니다.
영화 포스터
포스터를 표시할 때 기기가 KMDb, TheTVDB 또는 Wikimedia Commons의 이미지 서버에 접속합니다. 해당 서버는 이미지 요청을 처리하는 과정에서 접속 IP 주소와 앱 접속 정보를 받을 수 있습니다.

Firebase와 정보 처리 위치

가람랩은 Google의 Firebase를 이용해 로그인, 계정 데이터 동기화와 삭제, 개봉일 변경 푸시 알림 전달을 처리합니다. 로그인 또는 재인증을 선택하면 위 로그인 정보가 암호화된 네트워크를 통해 미국의 Firebase Authentication으로 전송되어 인증과 보안에 사용됩니다. 계정 기능을 사용하지 않으려면 로그인 없이 개봉 일정과 기기 내 관심목록을 이용할 수 있습니다.

현재 개발 앱이 연결하는 Cloud Firestore 데이터베이스는 대한민국 서울 리전에 있습니다. 계정 동기화를 이용하면 계정별 동기화 정보가 그 리전에 저장됩니다. 출시용 데이터베이스의 위치가 달라지는 경우 적용 전에 이 페이지에 안내합니다.

Firebase 서비스에 연결할 때 전송 구간을 암호화합니다. 앱의 계정별 동기화 정보는 해당 계정으로 로그인한 경우에만 읽고 변경할 수 있도록 접근을 제한합니다. Firebase의 보안과 정보 처리 방식은 Firebase 개인정보 보호 및 보안 안내에서 확인할 수 있습니다.

웹 방문과 문의

이 문서 사이트는 GitHub Pages에서 제공됩니다. GitHub는 사이트 보안을 위해 방문자의 IP 주소를 기록하고 보관합니다. GitHub의 처리 방법은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

문의 메일을 보내면 발신 이메일 주소와 본문에 적은 정보를 접수합니다. 가람랩은 내용을 확인하고 처리 결과에 회신하는 데 사용합니다. 문의 메일의 수신과 회신에는 Google Gmail을 사용합니다. Google 개인정보처리방침에서 메일 서비스의 정보 처리 방식을 확인할 수 있습니다.

보관과 삭제

  • 기기에 저장한 목록과 설정은 앱에서 해당 항목을 정리하거나 기기의 앱 데이터를 삭제할 때까지 보관합니다. Android에서는 기기 설정에서 영화달력의 앱 데이터를 지울 수 있습니다. 기기 백업에는 운영체제와 앱의 백업 설정이 적용됩니다.
  • 계정과 동기화 정보는 계정 삭제 요청을 처리할 때까지 보관합니다. 요청을 처리할 때 로그인 계정과 서버의 관심목록, 팔로우, 알림 설정 및 동기화 기록을 삭제합니다. 계정 식별자와 처리 시각은 기존 세션의 접근을 차단하고 삭제 완료를 확인하는 데 필요한 기간 동안 보관합니다. 자동 만료가 설정된 환경에서는 삭제 완료 24시간 후 만료 대상으로 지정합니다.
  • Firebase Authentication은 보안에 쓰이는 접속 IP 기록을 수 주간 보관할 수 있습니다. Firebase 안내에 따르면 삭제 요청을 받은 인증 정보는 서비스 시스템과 백업에서 180일 이내에 제거됩니다.
  • 캘린더에 저장한 일정은 해당 캘린더에서 삭제할 수 있습니다.
  • 문의에 필요한 정보는 요청 처리가 끝날 때까지 보관한 뒤 메일함에서 삭제합니다. 관계 법령에 따라 보관 의무가 생기는 경우 규정된 기간 동안 보관합니다.
